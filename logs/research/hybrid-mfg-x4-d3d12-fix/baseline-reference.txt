D3D12 DEBUG LAYER DIAGNOSIS:
1) ClearUnorderedAccessViewUint / ClearUnorderedAccessViewFloat (9 errors):
   "Specified descriptor handle ptr=... points to a descriptor heap type that is CPU write only, so reading it is invalid. UnorderedAccessViewCPUHandle is the issue."
   Cause: The harness used a single descriptor heap created with D3D12_DESCRIPTOR_HEAP_FLAG_SHADER_VISIBLE.
   D3D12 API specification requires ViewCPUHandle to reside in a non-shader-visible descriptor heap (D3D12_DESCRIPTOR_HEAP_FLAG_NONE) because shader-visible heaps are typically write-combined memory where CPU reads are invalid or prohibited.
2) CreateCommittedResource warnings (2 warnings):
   "Ignoring InitialState D3D12_RESOURCE_STATE_UNORDERED_ACCESS. Buffers are effectively created in state D3D12_RESOURCE_STATE_COMMON."
   Cause: Buffers in DEFAULT heap were initialized directly to D3D12_RESOURCE_STATE_UNORDERED_ACCESS, which violates D3D12 buffer creation rules. Buffers must be created in D3D12_RESOURCE_STATE_COMMON and explicitly transitioned to UNORDERED_ACCESS.
