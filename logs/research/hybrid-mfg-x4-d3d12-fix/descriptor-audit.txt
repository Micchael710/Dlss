EXPERIMENT: HYBRID_MFG_X4_D3D12_VALIDATION_FIX
API SPECIFICATION CHECK:
According to ID3D12GraphicsCommandList::ClearUnorderedAccessViewUint / Float:
- ViewGPUHandleInCurrentHeap: Must reference an initialized UAV descriptor within a shader-visible descriptor heap (D3D12_DESCRIPTOR_HEAP_FLAG_SHADER_VISIBLE) currently bound via SetDescriptorHeaps.
- ViewCPUHandle: Must reference an initialized UAV descriptor within a NON-shader-visible descriptor heap (D3D12_DESCRIPTOR_HEAP_FLAG_NONE). Driver CPU access to descriptor metadata from write-combined / GPU-visible memory is prohibited.
- pResource: Associated resource to clear.

DESCRIPTOR HEAP CONFIGURATION:
1. Shader-Visible Heap:
   Variable: heap
   Type: D3D12_DESCRIPTOR_HEAP_TYPE_CBV_SRV_UAV
   NumDescriptors: 10
   Flags: D3D12_DESCRIPTOR_HEAP_FLAG_SHADER_VISIBLE
   Role: Provides ViewGPUHandleInCurrentHeap (and shader root descriptor tables).
2. Non-Shader-Visible CPU Heap:
   Variable: cpuHeap
   Type: D3D12_DESCRIPTOR_HEAP_TYPE_CBV_SRV_UAV
   NumDescriptors: 10
   Flags: D3D12_DESCRIPTOR_HEAP_FLAG_NONE
   Role: Provides ViewCPUHandle for ClearUnorderedAccessViewUint / Float.
